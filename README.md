# Stockly - Inventory Management System
Next.js + MongoDB + JWT auth.
Run: double-click start.bat (Windows). Pehli baar .env.local me MONGODB_URI aur JWT_SECRET bharna hai.
Features: register/login/logout, password validation, protected pages, CRUD, dashboard stats, search, filter, pagination, role-based access (first user = admin), responsive UI.
Author: Jotish kumar
Bonus: image upload (resized, stored in MongoDB), mock payment/sell flow with orders + revenue, low-stock email (Resend, optional), admin users panel, CSV export, dark mode.
